# projects.maxistar.me

Landing page for Maxim Starikov's open-source projects.

## Projects

- **[3D Models](https://projects.maxistar.me/3d_models)** — Parametric 3D models for printing (OpenSCAD + build123d)
- **[ztools](https://ztools.org)** — Zero-dependency reactive UI runtime for the browser
- **[notes-md](https://github.com/maxistar/notes-md)** — CLI tool for managing a Markdown knowledge base with tags and Git sync
- **[preloader.org](https://preloader.org)** — Animated preloader/spinner generator
- **[Watchface](https://github.com/maxistar/watchface)** — WearOS watch face collection
- **[MorseTrainer](https://github.com/maxistar/morsetrainer)** — Android app for learning Morse code
- **[GitSync](https://github.com/maxistar/git-sync)** — Android app to sync files with a Git repository
